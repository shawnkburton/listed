## September 28 real-data update

Property cards now use five actual REALTOR.ca image URLs for each of the 20 houses, stored in `lib/nearby-properties.json`, with REALTOR.ca and brokerage attribution. Rights for public redistribution have not been granted by this task; this is a local research preview.
